# 13 — Real-World SQL Projects

## Goal
Build complete database systems instead of isolated query exercises.

## Projects
1. Banking transaction analytics
2. E-commerce orders and inventory
3. Hospital patient and appointment reporting
4. School attendance analytics
5. API production-support incident database
6. Job application tracker
7. Expense management system

## Standard lifecycle
Requirements → ER Model → Schema → Constraints → Seed Data → Queries → Indexes → Security → Reports → Tests → Troubleshooting → Documentation

## Required questions
- What is the business problem?
- What is the grain of each table?
- What are the keys?
- Which relationships exist?
- Which rules belong in constraints?
- Which queries are critical?
- Which indexes support them?
- What happens under concurrent writes?
- Who can access the data?
- How is it backed up and recovered?

## Definition of done
Another learner should be able to clone the project, understand the model, run it locally, test the main workflows and explain the design decisions.
