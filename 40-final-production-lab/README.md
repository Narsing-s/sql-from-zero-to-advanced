# 40 — Final Production Simulation

Run a complete incident-to-recovery exercise.

1. Deploy a realistic schema and workload.
2. Introduce a slow query and connection pressure.
3. Create blocking and replication lag.
4. Detect the issue from metrics and SQL evidence.
5. Apply a safe mitigation.
6. Perform a controlled schema change.
7. Simulate bad data and recover it.
8. Restore a backup in a separate environment.
9. Measure RPO/RTO.
10. Produce an RCA and prevention plan.

Completion requires evidence, commands, outputs and lessons learned—not only written answers.
