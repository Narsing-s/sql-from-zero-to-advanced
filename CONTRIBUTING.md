# Contributing 🤝

Thanks for helping other SQL learners!

## Good contributions
- New exercises
- Better explanations
- PostgreSQL corrections
- Real-world scenarios
- Performance examples
- Interview questions
- Translations
- Typo/documentation fixes

## Guidelines
1. Fork the repository.
2. Create a focused branch.
3. Keep examples runnable on PostgreSQL.
4. Explain expected output for exercises.
5. Do not include passwords, API keys or private data.
6. Open a pull request with a clear description.

Beginner-friendly contributions are welcome.
