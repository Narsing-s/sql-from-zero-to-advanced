# 35 — PostgreSQL Complete Reference Gap Closure

This final extension tracks advanced areas exposed by the PostgreSQL 18 documentation that are easy to omit from an SQL curriculum: information schema, system views, client protocol, JIT, parallel query, table sampling, background workers, archive modules, replication progress, OAuth validator modules, backup manifests, error codes, limits and supplied extensions.

The goal is not to make every learner write server extensions. The goal is to know that these capabilities exist, when they matter, and where to investigate them.
