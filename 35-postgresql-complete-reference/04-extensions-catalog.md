# Extension catalog

Review supplied extensions and modules such as pg_stat_statements, pg_trgm, btree_gin, btree_gist, citext, hstore, ltree, pgcrypto, tablefunc, unaccent, uuid-ossp, lo, test_decoding and TABLESAMPLE modules.

Before enabling an extension in production, document trust model, privileges, upgrade path, backup/restore behavior and compatibility with major-version upgrades.
