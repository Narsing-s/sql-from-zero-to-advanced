# 34 — Final SQL/PostgreSQL Mastery Checklist

Before calling the curriculum complete, learners should be able to:

- model relational data and constraints
- write and explain complex SQL
- reason about NULL, joins, windows, recursion and CTEs
- design indexes and read execution plans
- troubleshoot locks, waits and slow queries
- explain MVCC, WAL and vacuum
- secure roles, privileges and RLS
- handle JSON/JSON_TABLE and advanced PostgreSQL types
- design migrations and backfills safely
- operate backups, PITR and restore drills
- explain replication, HA and failover
- monitor capacity and query health
- test schemas and migrations in CI
- perform an upgrade rehearsal
- diagnose a production incident and write an RCA
- complete at least one end-to-end production capstone.
