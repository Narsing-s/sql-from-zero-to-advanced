# 25 — Capstone Projects

## A — Production Banking Database
Constraints, transactions, idempotent transfers, audit history, indexes, RLS, monitoring, backup/restore and recovery drills.

## B — Event/ETL Platform
Incremental ingestion, watermarks, late data, SCD2, deduplication, quality checks and partitioning.

## C — Highly Available Service Database
Replication, failover, RPO/RTO, observability, migration strategy, capacity planning and incident runbooks.

Each capstone requires architecture, schema, seed data, SQL labs, failure scenarios, performance tests, security review, migration history and interview questions.
