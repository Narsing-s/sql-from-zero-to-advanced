# Beginner Exercises

1. Find all customers from Visakhapatnam.
2. Find customers born after 1994.
3. Return only first name and email.
4. Find the two highest account balances.
5. Find customers whose name starts with A.
6. Count the customers.
7. Change one customer's city.
8. Find accounts with balance greater than 30000.

Write each query yourself before checking other examples in the repository.
