## Suggested study sequence

### Beginner
SQL basics → SELECT → WHERE → ORDER BY → INSERT → UPDATE → DELETE → NULL → constraints.

### Intermediate
JOINs → GROUP BY → HAVING → subqueries → EXISTS → CASE → set operations.

### Advanced
CTEs → recursive CTEs → window functions → views → functions → procedures → triggers.

### Engineering
Transactions → isolation → locks → indexes → EXPLAIN → security → JSONB → partitioning.

### Production
Observability → troubleshooting → deadlocks → slow queries → data quality → migrations → recovery.

### Interview
Explain every concept in three ways:

1. What it is.
2. Why it is used.
3. What can go wrong in production.

## Learning rule

Prefer official documentation when behavior is database-specific. Always verify PostgreSQL-specific syntax against the PostgreSQL version you are using.
